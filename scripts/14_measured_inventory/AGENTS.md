# Package scope and execution boundary

This package performs a prospective source-preserving measured-outcome inventory
for the exact six soil-response tracks and source records in RESPONSE_TRACKS.json.
Read PROTOCOL.txt and HPC_ONLY_ANALYSIS_POLICY.md before changing or running it.
Original source cells, dates, units, methods, values, depth literals and corrected
identity/exclusion/merge decisions are immutable. Reviewed method descriptions
belong in separate fields. Exact source pins/forms only; no fuzzy analyte aliases.

Scientific inventory/preprocessing, finite/censor/duplicate classifications,
source verification checks, support/eligibility counts, scientific fixtures,
scientific report/figure rendering and numerical analysis execute only on a
genuine Puma Slurm compute node verified by hpc_guard. Never import/run the
scientific inventory module locally, and never fabricate a Slurm environment.
Local immutable source/PDF/code reading, syntax checks, administrative hashes,
document editing and fixed editorial workflow diagrams are permitted.

No response conversion, imputation, aggregation, effects, p-values, models,
forecasts or scenario curves are authorized in this package. Original lab rows
are source representations rather than independent biological replication.
R0025/lab34082 remains soil-only and has neither a confirmed physical-plot key
nor an approved 16S join. Whipstone Annual 2025 extends pH only; organic carbon
must not replace LOI OM and nitrate must not be invented. H3A and KCl nitrate,
Annual and blackberry systems, and Oatman older/new fields stay separate.

Preparation/static review is PREPARED_NOT_SUBMITTED, with Puma checks pending.
Successful computation leaves scientific and visual review pending until the
returned artifacts are inspected. Preserve historical job/receipt states and
write dated editorial acceptance separately. A completed inventory never
approves a statistical model, predictive validity or ten-year forecast.
