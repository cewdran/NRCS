# Puma-only scientific execution

Every scientific numerical operation and scientific figure/report in this
package must execute on a genuine allocated Puma compute node. The real Slurm
guard precedes scientific imports, source-data reads and fixtures. Login-node
submission checks are administrative only; an unresolved compute-only Python
symlink on the login node does not imply a failed runtime. The allocated node
must verify the existing Python module, READY record, exact build and versions.

No source data or prior run is overwritten. Compute the new 2024 annual-round
diagnostic in a fresh immutable run. Stage and byte-verify the completed original
2025 engine and repaired report; do not rescore those historical errors. Scientific
and visual review of new outputs remains pending until the result bundle returns.

Local release checks cover syntax, manifests, code review and genuine guard
refusals only. Local editorial workflow documents contain recorded facts, not
new source counts, fits, predictions, error metrics, or scientific figures.
