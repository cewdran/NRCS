# NRCS association package

All numerical preprocessing, matrix transformations, statistics, numerical
self-checks and data-derived reports/figures must run on verified Puma Slurm
compute nodes. Local inspection, AST and shell syntax checks, byte checksums,
packaging and non-data workflow drawings are permitted.

Preserve all frozen source bytes and historical run statuses. Stage private
source snapshots and verify original/private hashes before and after work.
Use exact corrected library/sample identities and existing inclusion flags.
Do not split technical merges, clone composites, pool visits into independent
replicates, guess missing identities or harmonize undocumented assay methods.

Do not change frozen feature references, primary nomination rules or global
families after looking at effects or p-values. Report exclusions, descriptive
cohorts, failed eligible tests and sensitivity population differences.
Predicted functions represent inferred genomic potential. Alpha-diversity
endpoints originate from the same counts and are explicitly exploratory.

Submission, scheduler completion and scientific acceptance are separate states.
Actual Puma execution must be documented; scientific and visual review remain
pending until returned outputs are inspected. No forecasts or predictive
validation are generated by this package.
