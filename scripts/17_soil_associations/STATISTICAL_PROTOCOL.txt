NRCS TAXONOMIC AND PREDICTED-FUNCTION ASSOCIATIONS
Prospective core protocol prepared 2026-10-09; statistical execution and numerical self-checks await Puma Slurm.

Scope and execution
This supplement addresses sample-matched associations of bacterial and archaeal genera, families, and PICRUSt2 inferred functional features with measured numeric parameters and prespecified categorical treatment/crop metadata. It does not re-estimate the original 16S counts, PICRUSt2 predictions, source corrections, or prior manuscript results. All aggregation, transformation, matching, statistical computation, plots, and self-check execution are to occur only in an allocated Puma Slurm job. Local work is restricted to source inspection, programming, syntax checking, and package/provenance preparation.

Interpretation
Sequencing counts are compositions, and a component's log-ratio association with an environmental measurement is not an association of its absolute abundance (Gloor et al., 2017). Predicted gene-family/pathway abundances represent inferred genomic potential; they are not measured genes, expression, process rates, or evidence of causal activity (Douglas et al., 2020; Wright and Langille, 2025). Environmental prediction accuracy cannot be assumed from strong correlations of predicted and observed gene-profile compositions (Sun et al., 2020). Genera and families are separate aggregations of the same source data, not independent biological confirmations; EC, KO, and pathway annotations also overlap biologically.

Source and identity gates
1. Require the accepted corrected metadata/counts and functional-prediction/sensitivity source runs, their source job IDs, integrity manifests, provenance receipts, and exact current library identities. Use source taxonomy if available; do not infer genus/family names from ASV IDs or function annotations.
2. Keep bacteria and archaea separate. Preserve corrected merged technical-library counts and library identities; never split a merged library into pseudo-replicates.
3. Exact metadata keys must identify farm, year or sampling event, crop/cultivar, sample matrix, physical plot, laboratory record, analyte, units, assay/method, and accepted crosswalk status. Unknown or ambiguous keys are a recorded skip, not an opportunity for fuzzy matching. Prefer a declared source crosswalk to string parsing.
4. A numeric parameter must be finite, uncensored, in compatible units, and have a traceable source record. Never turn a non-detect, blank, held result, or intentional exclusion into zero. Different laboratory methods and matrices are separate strata. Same-named variables in different units or extraction methods are not automatically interchangeable.
5. No nearest-neighbor or year-only joins between porewater, soil, plant, or unmatched collections. An environmental pooled specimen shared by several sequencing libraries is not several independently measured outcomes. Unless a source-supported single biological-unit aggregation can be defined, skip inferential tests with duplicated laboratory-record identities.
6. Distinct sequencing libraries from the same physical plot/event/matrix require the source's approved biological-unit aggregation rule. Unresolved duplicates fail the unit gate. A farm-unique record is not farm replication.

Compositional transformation (proposed)
For each farm, domain, and feature class, freeze the primary feature universe using all positive-observed features in that farm's source-approved primary cohort before endpoint matching. The same frozen universe is reused for zero, depth, and prediction-version sensitivity scenarios. Taxonomic family and genus tables are independently aggregated by complete lineage keys. Preserve unclassified lineage-specific bins in the denominator and do not combine unrelated missing genus labels into a purported genus. Drop only features zero in every accepted source sample; record this non-statistical removal. Do not change the denominator after prevalence filtering, missing-outcome filtering, or stratum selection. The existing function panel is an annotation layer only; all eligible named functions are screened, and CLR is computed against the complete same-class reference universe.

The recommended zero rule is multiplicative replacement on closed proportions, which preserves nonzero component ratios (Martin-Fernandez et al., 2003). For sample s with positive total, let p_j=c_j/sum(c). With z zeros, delta_s=min(1e-6, 0.5*min(p_j>0), 0.5/z); replace each zero by delta_s and multiply all nonzero proportions by (1-z*delta_s). If z=0, use p unchanged. Record delta_s, zero fraction, and replaced mass. Then CLR_j=ln(p'_j)-mean_k ln(p'_k). Reject nonfinite/negative features, zero-total samples, nonpositive replacements, and invalid simplex sums. Bacteria/archaea, genus/family, and EC/KO/pathways each have their own fixed universe; never merge unlike classes into one CLR.

Primary epsilon is 1e-6, with prespecified 1e-7 and 1e-5 sensitivity calculations. These are pragmatic choices rather than known optimal parameters. Sensitivity does not cure structural zeros or sparse-data bias; report zero prevalence and avoid absolute-abundance language (Kumar et al., 2018). Count-pseudocount CLR is an alternative only if it is explicitly selected/frozen before execution and its units/depth sensitivity are disclosed.

Numeric association layer A: independent cross-sections
Primary inference is within farm x analytic_system x plant_type/crop x cultivar x exact collection event/date x endpoint dataset x parameter x units x compatible assay-method strata. Sequence source rows must have primary_included true and be retained selected analysis_observations; primary_included is not replaced with a newly invented read-depth cutoff. Exact joins use farm, sample_key, and collection date; composite laboratory outcomes are not cloned and dates are not imputed. The existing source depth_sensitivity_included flag is evaluated as a separately reported globally merged diagnostic sensitivity family; numeric and categorical hypotheses share that scenario family. Each feature/parameter pair contains exactly one microbial composition and one matched measurement for each independently identified biological plot. Retain an explicit matched-unit table and an exclusion/duplicate audit. Never pool all years into an ordinary correlation.

Spearman rho is Pearson correlation of average ranks of feature CLR and numeric parameter among matched units. Ties use average ranks. Pragmatic prespecified inferential screens are n>=6 independent units, feature positive in at least three units and at least 50% of matched units, and no duplicate plot or shared environmental-record keys. Inferentially eligible candidates with fewer than three distinct transformed feature or endpoint values retain reported p=null and enter correction as p=1; this prevents silently shrinking the multiplicity family after a degenerate statistic. The same holds for an otherwise eligible numerical failure. Variance/unique-value requirements are computational validity gates, not significance selection. n=3-5 permits a descriptive rho and scatterplot, with p/q blank and status DESCRIPTIVE_ONLY_TOO_FEW_INDEPENDENT_UNITS. n<3 yields a reason-coded skip. Constant/insufficiently varying vectors cannot produce an interpretable statistic; their reason and eligibility are recorded. These gates protect against trivially unsupported calculations but do not establish adequate power.

The main estimand is a marginal association across treatments within the declared stratum; it can reflect treatment differences, shared management, or unmeasured gradients. It is not treatment-adjusted or causal. Within-treatment point correlations are emitted as diagnostics when at least three independent plots are available, with p/q missing. A partial rank correlation residualized against ranked log-depth is a diagnostic only, with no p/q or claim of predictive/causal adjustment.

Two-sided p-values use |rho| and the null of exchangeability of measured endpoint labels among independent plots in the declared stratum. Exact enumerations include every index permutation and identity; tied assignments must retain their multiplicity. Compute p=b/M without a Monte Carlo correction when all M assignments are enumerated. Exact enumeration is used for n<=8 (n!<=40,320). Otherwise draw B=19,999 independently seeded random index permutations and compute p=(b+1)/(B+1), including ties as at least as extreme with a documented numeric tolerance (Phipson and Smyth, 2010). Report exact/random mode, M if known, B, seed, minimum attainable p, and exchangeability assumption. A zero p-value is invalid. Asymptotic Spearman p-values are not substituted for insufficient permutation resolution.

The potential permutation computational budget should be evaluated before packaging. Reuse a stratum's endpoint permutation rank matrix across features with the same missingness mask, and process feature batches rather than constructing a features x permutations x samples tensor. Exact enumeration of n=8 can otherwise be unnecessarily expensive. Fewer allowed assignments may make FDR discoveries unattainable; this is reported, not resolved by pooling non-independent units or silently relaxing error control.

Repeated observations
The same physical plot may appear in separate year/event-specific tests, but never twice inside one test. Repeated-event tests remain dependent and are covered by conservative global BY adjustment. Crop-adjusted pooled tests, matched-change tests, repeated-measures correlation models, and prospective forecasts are outside this package's implemented scope. They require a separate prespecified model rather than sample-wise shuffling (Bakdash and Marusich, 2017; Winkler et al., 2014).

Categorical association layer B: treatment and observed crop groups
Farm, crop/cultivar, genotype, treatment, sample matrix, and sampling-event labels are categories, not ordered numeric correlation outcomes. Numeric-looking codes are treated as labels; no integer coding followed by Spearman. Existing accepted whole-community/functional treatment comparisons remain historical results; this supplement adds separate feature-specific categorical hypotheses with its own association_type in each canonical test ID. The implementation labels the crop-within-treatment layer CROP; CROP_WITHIN_TREATMENT is its expanded protocol name.

TREATMENT omnibus tests are within farm x analytic_system x crop_key x exact collection event, using one feature composition per independently identified biological plot. Crop_key carries the source-supported plant_type/crop and cultivar identities and must be declared before testing. The response is feature CLR, and treatment labels are unordered groups. A treatment contrast known to be confounded with field side (Oatman2025) remains descriptive; valid independent plot counts alone do not resolve that confounding.

CROP_WITHIN_TREATMENT omnibus tests are within farm x analytic_system x exact collection event x treatment. Compare only source-supported crop/cultivar groups represented in that one stratum. Control/reference collections with ambiguous or mixed crop identities are excluded from this layer through the declared source design audit, never by a favorable effect. No cross-farm, cross-system, or across-year crop pooling is allowed. The observational estimand can reflect crop identity, spatial position, management history, or other unmeasured conditions; a crop group comparison is not a causal crop effect. A farm-level contrast with one farm per condition remains confounded (Hurlbert, 1984).

For either categorical kind, inferential candidate gates are at least six distinct independent plot units, at least two groups with at least two independent plots in every observed group, and feature detection in at least three plots and at least50% of the matched cohort. The core retains every group supplied in the declared matched cohort; no row or group is dropped based on its effect. Scenario cohort identities and group counts expose source-flag or zero-profile losses. The estimand is explicitly limited to the retained observed groups; a missing source arm is not represented as a completed comparison of all planned arms. Three to five plots can yield descriptive effect/group summaries with p/q missing; a group with fewer than two plots cannot yield inference. Retain group levels, counts, and medians of featureCLR; medians are descriptive values, not confidence intervals or post-hoc pairwise tests. Missing labels, duplicated plot IDs, and nonfinite feature inputs are recorded failures without silent row dropping. A constant response after structural/detection eligibility keeps rawp missing, correction_eligible true, and conservative adjustment input1.

The canonical effect is rank eta-squared: sum_g n_g*(mean rank in groupg - overall mean rank)^2 divided by sum_i*(rank_i-overall mean rank)^2, using average ranks for ties. It is unsigned; larger values indicate stronger separation among categories. An untested rawCLR groupR2 is a separate descriptive diagnostic. No signed directional claim follows from an omnibus effect, and no causal or asymptotic ANOVA/Kruskal-Wallis p-value is substituted. Canonical inference uniformly permutes categorical labels over the independent plot units while preserving group sizes. This assumes conditional exchangeability within the declared observational stratum; field randomization has not been established.

When n<=8, enumerate all unique multiset label assignments including the observed assignment, with assignmentspace=n!/product_g(n_g!), and use p=extreme/space for null ranketa-squared at least as large as observed. Exact unique label enumeration avoids redundant index permutations; counting index permutations with their equal multiplicities would yield the samep. For n>8, draw19999 independent uniformly permuted label vectors with replacement and use the plus-onep=(extreme+1)/20000. Record full finite assignmentspace, evaluated count, exact/MonteCarlo mode, seed and numeric tolerance. The probability grid is only a lower bound on attainablep; ties, symmetry under group-label permutations, and coarse finite assignment spaces may raise the true minimum. Repeated MonteCarlo draws never create independent biological replication (Phipson and Smyth,2010; Winkler etal.,2014).

Sensitivity and reporting
Freeze candidate nomination from the untransformed primary reference within each declared stratum before any association effects/p-values. Repeat zero-replacement sensitivities on the same matched rows, fixed denominator, primary-nominated features and hypothesis IDs; variant and analysis_kind still distinguish output row IDs. Numeric and categorical cores validate current aligned rows and re-evaluate current count/detection gates. The supplied positive mask must be the primary-reference observed-detection mask aligned to those current rows, not a detection mask selected from a more favorable sensitivity profile.

The existing depth flag can select a smaller independently matched cohort. Re-gating that subset can therefore produce fewer than six plots, sparse feature detection, singleton categorical groups, or a different correction-eligible diagnostic set. Record those scenario-specific failures, currentn, independent unit identities, detection fraction, group counts, and family-size differences explicitly. Such diagnostics are comparisons of changed populations; they are not same-population robustness confirmations. Never promote a feature that failed the primary nomination, relabel a skipped sensitivity as agreement, or replace the primary test with a favorable sensitivity result. Prediction-version diagnostics with changed nonzero-profile eligibility require an explicit population-difference label; no silent sample alignment or population merging is allowed. A zero transform on identical rows cannot change detection nomination; otherwise eligible degeneracies retain missing rawp and enter that scenario correction as1.

Repeat the selected transform sensitivity on the same matched rows, fixed denominator, candidate features, and test IDs. Do not select a different feature universe or choose the most favorable sensitivity p-value. Summarize matched sample size, detection fraction, ties, zero-replacement burden, direction agreement, and absolute rho change. Leave-one-plot-out diagnostics are not included in this package; within-treatment and depth diagnostics are reported as described above. These diagnostics do not yield extra discovery tests. Predicted-function versions/NSTI thresholds use the previously accepted sensitivity sources; never combine different versions as independent observations. A primary association supported only by one zero choice, one low-quality prediction setting remains fragile and is labelled accordingly.

Parallel worker partition and global multiplicity
Twelve independent workers are 3 farms x 2 domains x {taxa, functions}. Each taxa worker handles Family and Genus; each functions worker handles EC, KO, and MetaCyc. Workers read original sources and write only to their owned shard directory. Package preparation freezes the source paths/hashes, protocol, parameter scope and expected worker IDs. Each worker verifies these inputs, constructs the exact matched cohorts, freezes its feature reference and primary detection screen, and emits the cohort/screen tables before calculating effects or p-values. Canonical test IDs are deterministically generated from the frozen shard, class, cohort, feature and scenario fields.

Every worker emits raw effect/p-value rows, descriptive/skip rows, matched-unit audit, and completion/validation receipt. Workers do not issue final q-values or call individual unadjusted hits significant. A dependent consolidation job requires all expected workers completed successfully and verifies the unchanged package/protocol manifest, source digests, all prerequisite scheduler and self-check receipts, manifested output files, declared shard/farm/domain identities, recorded output counts, and unique canonical test IDs. The reviewed worker code supplies the prespecified feature nomination and cohort logic; consolidation does not independently rerun feature nomination. Canonical hypothesis IDs include association_type(NUMERIC, TREATMENT or CROP), farm/domain/class/feature lineage or annotation ID/parameter and unit/method/declared stratum/collection event. Each output row also identifies the transform/source-depth/prediction-version scenario; otherwise different variants could collide.

The primary family contains every eligible primary numeric and categorical association in this NRCS supplement across all twelve workers, farms, domains, ranks/classes, measured outcomes, categorical analysis kinds, and strata, including otherwise eligible failures as p=1 for correction while keeping their reported raw p missing. Every zero-replacement sensitivity, existing source-depth sensitivity, and archaeal-original prediction diagnostic has its own globally merged family across expected workers; its eligible numeric and categorical tests are together, never separate favorable discovery families. Primary candidate features are screened before association effects/p-values and reused; no feature is chosen by a favorable sensitivity result. BY adjusted p-values are the conservative primary error-control summary under arbitrary test dependence; BH adjusted p-values are supplementary (Benjamini and Hochberg, 1995; Benjamini and Yekutieli, 2001). Sensitivity variants do not enter as additional discoveries, and never replace the primary p-value. Keep separate exploratory reports for raw rho and descriptive sparse strata. All eligible EC, KO, and MetaCyc features are screened. The existing fourteen-feature function panel is an annotation layer only, not a separate favorable discovery family or a restriction chosen from association results. Include family size, adjustment method, adjusted threshold, and inference limitations in every report. Reported skips/missing raw p-values remain missing, never zero or one. Only the conservative adjustment input replaces an otherwise eligible failed/missing p with one, with explicit audit counts.

Final outputs
Full feature-parameter tables with numeric rho and categorical ranketa-squared effect sizes, raw permutation p, global BY/BH adjusted p, detection/matching/independent n, strata, test status, permutation space/seed, and sensitivity diagnostics; complete design/matching/skip/multiplicity audits; limited annotated association dot plots and complete plot-selection legends generated on Puma; summary of data-supported vs descriptive-only associations; manuscript-ready Methods draft and peer-reviewed reference ledger. No ten-year extrapolation or prospective predictive validation is part of this supplement.

Output accounting and consolidation
Named feature/cohort combinations failing primary nomination remain fully recorded in feature_screen.csv.gz, not as redundant per-scenario test rows. Association tables contain primary-nominated feature/cohort hypotheses and their explicit scenario-specific results, descriptive estimates and skips. scenario_cohorts.csv records exact current units, primary population equality and excluded variant-only libraries. The global merge uses two streaming passes, numeric correction buffers and a temporary on-disk unique-ID index; only bounded display rows enter report/plot tables. Full result exports and aggregate counters retain all worker association rows. Display selection never modifies the discovery family.
